This is an archive + visualizer of the WBO Winning Combinations at WBO Organized Events - Beyblade X (BBX) Thread.

This archive includes:

- CSV Scraped HTML data of the WBO Winning Combos thread, The event threads associated with each post, and the Bracket links provided in each post/event thread (includes only first and final stage bracket format, participant count, and first few scores of each stage).
- Exported/Compiled JSON of cleaned combo data from the winning combos thread of all valid/complete combos, including event dates, first and final stage formats (if found), Ranked status, and placements (if found).
- Exported/Compiled JSON of bracket links with their extracted first and final stage, participant count, and points to win the match during first/final stage

This archive also include a graphical visualizer as well using a JS app, a separate README is included there on how to run the visualizer.
